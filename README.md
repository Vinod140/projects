#  my projects

📂 Projects Overview
1️⃣ Real-Time Object Detection Application

Tech Used: Python, YOLO, OpenCV, Tkinter, Pygame, Label Studio

Features:

Detects objects in real-time using webcam or mobile IP camera

Works with videos and images

Supports custom trained YOLO models

GUI built with Tkinter + Pygame

Workflow:

Capture frames (Webcam / Mobile / Video / Image)

Process frames with YOLO model

Display bounding boxes & labels in real-time GUI

Future Enhancements: Add object tracking & deploy on edge devices.

2️⃣ Area Price Prediction Website

Tech Used: Django, Scikit-learn, HTML, CSS

Features:

Predicts property price based only on area (sq. ft.)

Uses a Scikit-learn regression model (Linear Regression)

Django web app with clean HTML/CSS frontend

Workflow:

Train model on dataset (Area vs. Price)

Save trained model as model.pkl

User enters area → Django loads model → Predicts price

Future Enhancements: Add more features like location, bedrooms, bathrooms.

3️⃣ Voice & Text Translator (Streamlit App)

Tech Used: Python, Streamlit, Googletrans, SpeechRecognition

Features:

Text Translation between multiple languages

Voice Input → converts speech to text → translates instantly

Built in a single Streamlit file (no backend needed)

Workflow:

User selects source & target languages

Input text (or voice)

Translate using Googletrans API

Display translated result in real time

Future Enhancements: Add Text-to-Speech (TTS) and offline translation support.

4️⃣ Advanced GUI Calculator

Tech Used: Python, Tkinter, Math library

Features:

Basic Calculator (Add, Subtract, Multiply, Divide)

Scientific Functions (sqrt, power, trigonometry, log, etc.)
