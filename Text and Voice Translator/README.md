# nlpproject
A Streamlit-based web application that translates text or spoken input into multiple languages in real time. Built in a single Python file, it is lightweight and easy to run.

🚀 Features

Text Translation – Type text and get translations instantly.

Voice Input (Speech-to-Text) – Speak directly and auto-convert to text, then translate.

Multiple Languages Supported – English, Hindi, French, Spanish, and more.

Simple UI – Clean and user-friendly interface built with Streamlit.

Single File Project – Easy to run without extra backend.

🛠️ Tech Stack

Framework: Streamlit

Programming Language: Python

Libraries Used:

googletrans – For translations

speechrecognition – For capturing and converting voice to text

streamlit – For web interface

⚙️ Workflow

Select Source & Target Languages from dropdown.

Choose Input Type:

Text Box → Enter text manually.

Speak Button → Speak and convert to text automatically.

Translation Process – Input is sent to translator library.

Output Display – Translated text shown on the app.
